## Decided (with the reasoning)

- **A number in prose must have something that recomputes it; if nothing can,
  do not write the number there.** Commit messages are the clearest case: a
  count in one cannot be corrected without rewriting its SHA, which invalidates
  every audit referencing it. Verification numbers go in the PR body, which
  `scout-preflight.yml` re-checks on `synchronize`. Full entry in CLAUDE.md.
- **Stale `Suite:` trailers on #60's inherited commits are not amended.**
  Rewriting three commit messages does not make a future one correct, and the
  rebases had already invalidated the SHAs anyway. The fix is not writing them.
- **The `.game-grid` stretch deliberately reaches My Picks too.** Both grids
  share the class; splitting by id would make one class mean two things.
  Measured: My Picks rows were ragged by up to 18px and are level now.
- **The coin-flip track record leaves the card face, the underpowered band
  stays.** "Too few games to report a rate" is a statement about missing
  evidence that nothing else on the card implies. It affects zero cards today,
  so keeping it costs nothing and matters early in a real season.

## Surprised us

- **A guard aimed at the build cannot see a timing bug in a collection-time
  predicate.** `test_build_artifacts_exist.py` asserts the conftest built the
  page — and it did. The decorator simply asked before it existed.
- **A measurement that cannot come out any other way is not evidence.** Booth
  reported My Picks rows as uniform, spread 0.0px, measured with
  `align-items: stretch` already applied — which makes the spread zero by
  construction. The first correction repeated it. Real natural spread: 18px.
  An audit is not exempt from this.
- **`verify_matchup_cvd.worst_dE()` shades its inputs before simulating.**
  Right for two team fills that touch in a bar, wrong for two tokens. It
  reported 34.1 dE00 for a pair that is really 10.8 — wrong in the FLATTERING
  direction, attached to the one sentence admitting a residual risk.
- **Explaining a defect reproduces it.** Three times: a guard flagged its own
  docstring quoting the banned decorator; a comment tripped the check that
  forbids its phrasing; writing a section tag with angle brackets inside a CSS
  comment unbalanced the section counter, because a CSS comment is still
  inside the document it describes.
- **The only thing that conflicted across three rebases was a hand-maintained
  count of the repository's own contents.** Not code. And because it is
  guarded, each rebase cost a minute instead of a false sentence.
