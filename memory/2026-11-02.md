## Learned

- GitHub's unauthenticated API allows 60 calls an hour; a poll of three PRs is about nine. Poll one PR at a time.
- A PR's description cannot be edited from the PC (GitKraken creates, never updates), so a description that goes
  stale after a merge of main means a new PR from a new branch, or Mark editing it in the web UI.
- Scout's preflight reads any number near a test file's name as the suite count; quote only the full figure.
- CI logs need a sign-in: a red step is reproduced locally (the cloud container has Playwright; npm there cannot
  reach the registry, so build axe-core on the PC and stage it).
