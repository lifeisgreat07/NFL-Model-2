## Surprised us

- **The home page's theme button was dead on desktop since Stage 80 item 56 (2026-10-16).** The search button wears
  `.home-theme` for its shape, comes first, and is shown on desktop, so `querySelector('.home-theme')` bound the
  theme to it. tests/browser/check_theme.py said the home page had no button and never pressed it: a browser check's
  list of pages is a claim about the site that goes stale like any other.
- **A class used for shape is not a hook.** Look a control up by an id or a data attribute that only it carries.
- **Re-using a PR body means re-deriving every figure in it**, the collection split included (`suite_split.py`);
  bypassing go.ps1 skipped that step and cost #686 a discrepancy.
- **Splitting an ids file on spaces keeps the last id's newline**, and the runner reads it as a glob that matches
  nothing and drops it silently (183 run for 184 ids). scratch-nba/run_ids_file.ps1 trims and refuses a count that
  does not match the file.
- **A Booth audit can time out on a diff it finished before**: #686's first run was cancelled at 20 minutes, the
  re-run took six. Re-run once, as the rule says.
- **The built-in browser pane swallows the first real click after a script-triggered reload** (no event reaches the
  page, not even pointerdown in capture). Not a site bug; reload by navigating, or click twice and read events.

- **No digits in a commit message.** Scout reads "N case" or "N test" as a suite count, with no disclosure escape.
- **Stacked branches move each other's anchors.** Each NBA tab added a More-menu button or a render call, which broke
  `test_the_long_names_sit_under_more_as_they_do_on_the_nhl`, `nba-chrome-checks-label` and
  `nba-accuracy-page-never-built` one branch later. Only the full suite at each head found them; the accuracy case now
  anchors on `renderAccuracy();` and the call after it, which later pages leave alone.
