## Decided

- **Batch related 7.5 items into ~4 PRs, not 8.** Each audit costs usage and a
  manual trigger, and Booth reviews a coherent change better than a fragment.
  Explicitly NOT one giant end-of-stage PR: a large diff is where Booth's value
  drops most, and #40 and #41 each surfaced a real defect worth finding early.
- **Build the jargon guard first, red, with a shrinking allowlist.** Written
  afterwards it would have been fitted to whatever copy got written — ratifying
  the result instead of testing it.
- **Keep the Roadmap's content when merging it.** The plan said the "Done" list
  duplicated the Changelog. It did not: 7 model versions vs 16 mostly-product
  milestones, ~3 overlapping. Executing the plan literally would have destroyed
  the only record of the picks log, the calibration table, the deep-dive page
  and the nflreadpy migration.
- **Methodology gets in-page parts, not a flat merge.** It was already 10.7k
  visible characters; the three merged pages added 7.8k. Flat, that trades three
  tabs for one page nobody finishes.
- **Motion Primitives and Watermelon UI are React; this dashboard is one vanilla
  file.** Borrow the motion vocabulary, not the library. Recorded in CLAUDE.md
  under the Stage 8+ design tooling notes.

## Surprised us

- **`collect_agent_log.py` had never run.** Built, tested and mutation-covered
  in Stage 3, and nothing invoked it: no data file, and the generator had never
  heard of it. A tested component wired to nothing looks exactly like a working
  feature from inside the suite.
- **The mobile nav kept a dead Playoff Odds tab through #40 and onto main.**
  There are two navigations; #40 removed the sidebar button only. On a phone the
  tab opened a blank screen.
- **A guard defeated itself by reading the thing it was checking.** The merge
  left orphan `<section id="page-datasources">` tags inside Methodology, and the
  nav guard builds its list of real pages from exactly those tags — so the
  orphans made the deleted pages still look like they existed.
- **Three guards matched inside comments** in one session: a reference check, a
  workflow security check, and a build-record check that counted commented-out
  markup as present.
- **The Research-Only table had been malformed since it was written** — four
  declared columns, five of six rows supplying three, so outcomes printed under
  the wrong header. Only visible once removing a column shifted it far enough
  to see in a screenshot.
- **Booth caught a miscount that was known and then dropped from the summary.**
  The allowlist held nine, not eight; the ninth was a matcher phantom. Both
  facts were known when the PR was written and one did not make it into the
  sentence.
