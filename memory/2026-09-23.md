## Decided

- **Lock time: Thursday, before Thursday night's kickoff (Mark).** The
  Tuesday lock came before Wednesday's injury reports, so a sourced QB
  override almost never reached the pick. v2.5 exists to give the pick
  better QB information, and the old timing undercut it. Rejected: keeping
  Tuesday (no change, but the forward test would mostly score the schedule's
  listed starter), and locking each game before its own kickoff (best QB
  information, but several crons, a partly locked week, and new write-once
  and grading rules).
- **The rule is "lock if the first game comes before the next scheduled run
  plus 4 hours", not a calendar rule.** "The day before the first game"
  never locks week 18, which has no Thursday game. "Within N hours of
  kickoff" cannot both hold an ordinary week on Tuesday (~61h to Thursday
  night) and lock a Sunday-only week on Thursday (69.5h to a London
  kickoff). The slack is what sends Thanksgiving's 12:30 ET game to Tuesday:
  it is 90 minutes after the Thursday run.
- **A game that has already kicked off never gets a pick.** The Methodology
  page says every pick is locked before kickoff. Under the Tuesday lock that
  held by margin alone. Under the Thursday lock a failed run plus a manual
  one can meet it, so it is now enforced.
